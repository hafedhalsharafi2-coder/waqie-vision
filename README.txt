طريقة الرفع على GitHub Pages:
1) ارفعي الملفات نفسها لا ملف ZIP فقط.
2) تأكدي أن الصفحة الرئيسية اسمها index.html.
3) بعد الرفع، ادخلي Settings ثم Pages.
4) اختاري Branch: main ثم /root واضغطي Save.
5) انتظري حتى يظهر رابط الموقع.
