مشروع واقع الرؤية

صحيفة إلكترونية مهنية تتابع مشاريع رؤية السعودية 2030 وتشرح أثرها على المجتمع، الاقتصاد، التقنية، جودة الحياة، والسياحة بأسلوب صحفي واضح ومبسط.

فريق العمل - المجموعة العاشرة:
- حلا المطيري
- العنود السحيمي
- سميه خلاف
- ريم مشعان الحربي
- رواف الرحيلي

طريقة الرفع على GitHub Pages:
1) ارفعي الملفات نفسها لا ملف ZIP فقط.
2) تأكدي أن الصفحة الرئيسية اسمها index.html.
3) بعد الرفع، ادخلي Settings ثم Pages.
4) اختاري Branch: main ثم /root واضغطي Save.
5) انتظري حتى يظهر رابط الموقع.
