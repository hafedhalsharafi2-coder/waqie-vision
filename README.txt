ملاحظات:

- تم توسيع كل قسم ليشمل أكثر من موضوع فرعي مع عناوين وصور ونقاط مختصرة.
- الروابط الخارجية تفتح في تبويب جديد.

طريقة الرفع:
ارفعي الملفات نفسها إلى GitHub، وليس ملف ZIP فقط.


مجلد الصور:
- يحتوي المشروع الآن على مجلد images.
- يجب رفع مجلد images كاملًا مع ملفات HTML و CSS و JS.
- لا تحذفي مجلد الصور؛ لأن الصفحات تعتمد عليه لعرض الصور.

التحديث النهائي:
- تمت إضافة صفحة إنفوجرافيك وفيديوهات باسم media.html.
- تم نقل قسم المصادر والمراجع إلى صفحة تواصل معنا فقط.
- تمت إضافة روابط تفاعلية لمنصات الفيديو والتواصل الاجتماعي.
- يجب رفع مجلد images كاملًا مع الملفات.
